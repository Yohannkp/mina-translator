## Argot de Lomé (Kpɔ e wɔ)

L'argot de Lomé est essentiel pour capturer le langage quotidien réel.

### Expressions courantes

| Terme | Signification | Usage |
|-------|--------------|-------|
| kpɔ | voir/comprendre | "Wo kpɔa?" = Tu comprends? |
| dzrɔ | avoir peur | "Mɛ dzrɔ" = J'ai peur |
| flɛ | sortir/partir | "Mɛ flɛ" = Je pars |
| gba | donner/offrir | "Gba nyɔ" = Donne-moi ça |
| kaka | trop/beaucoup | "Kaka nyui" = Trop bien |
| kwi | travailler | "Wo kwi?" = Tu travailles? |
| fla | manger | "Mɛ fla mɔ" = Je mange bien |
| vɛ | non (familier) | "Vɛ vɛ" = Non non |
| ʋiʋi | mensonge | "Wo gblɔ ʋiʋi" = Tu mens |
| yovo | étranger/occidental | "Yovo la ba" = L'occidental arrive |
| kpalakpalada | confusion/chaos | Expression de désordre |

### Phrases argot示例

```
"Kpɔ dzi nyɛ!" → Comprends-moi bien!
"Mɛ flɛ fifi" → Je pars maintenant
"Gba nyɔ nyui" → Donne-moi quelque chose de bien
"Kaka kaka!" → Trop trop!
"Kwi mɔ nyɛ" → Travaille bien pour moi
"Wɔ kpɔa?" → Tu comprends?
"Mɛ dzrɔ blakpo" → J'ai très peur
"Vɛ vɛ, mɛ sɔ nyui" → Non non, je vais bien
```

## Format JSONL

Chaque phrase sera stockée au format suivant:

```json
{
  "instruction": "Traduis en mina cette phrase en français",
  "input": "Phrase en français",
  "output": "Phrase en mina",
  "theme": "domaine_parent",
  "sous_theme": "sous-catégorie",
  "validated": false,
  "tonalite": "haut|moyen|bas",
  "argot": false,
  "source": "nom_du_script_source"
}
```

### Annotation tonale

Le Mina est une langue tonale. Chaque phrase doit avoir une annotation tonale:

- **Ton haut** (´): Intensité émotionnelle, urgence
- **Ton moyen** ( ): Conversation neutre
- **Ton bas** (`): Calme, autorité, solemnité

### Validation requise

Toutes les phrases générées doivent être:
1. Linguistiquement valides en Mina
2. Pertinentes pour le contexte togolais
3. Validées par un locuteur natif
4. Variées en longueur et complexité

## Stratégie de Génération

### Phase 1: Collecte de données (Semaines 1-4)
- Collecter des phrases existantes de sources togolaises
- Récupérer des dialogues de tribunaux, hôpitaux, marchés
- Analyser les transcriptions audio disponibles

### Phase 2: Génération semi-automatique (Semaines 5-8)
- Utiliser les templates ci-dessus
- Appliquer des transformations grammaticales
- Vérifier la cohérence tonale

### Phase 3: Validation humaine (Semaines 9-12)
- Recruter des validateurs mina natifs
- Corriger les erreurs grammaticales
- Affiner les expressions idiomatiques

### Phase 4: Intégration et tests (Semaines 13-16)
- Fusionner avec le corpus existant
- Tester avec le modèle de traduction
- Ajuster selon les métriques de qualité
